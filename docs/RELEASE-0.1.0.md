# YoungBar 0.1.0

第一个公开版本。

## 功能

- 菜单栏收纳：可见 / 隐藏 / 始终隐藏三种状态
- 收纳条显示应用图标；点击隐藏项用 AXPress 原地打开，不闪菜单栏
- 菜单栏页：显示 / 隐藏 / 始终隐藏，一行一个；拖动或右键排序
- 外观：蓝 / 粉 / 黄 + 透明，主题色玻璃设置窗口，收纳条不透明度 30–100%
- 菜单栏按钮：省略号 / 爱心 / 星形 / 闪光 / 网格 / 自定义 PNG
- 全局快捷键 ⌃⌥B
- 崩溃恢复、路径/版本变化自动重登登录项

## 要求

- macOS 27
- 辅助功能权限（Device Control and Data Access）
- **不需要屏幕录制**

## 安装

1. 下载 `YoungBar-0.1.0.zip`，解压后拖进 `/Applications`。
2. 第一次打开：右键 → 打开（未公证的 app 会被 Gatekeeper 拦）。
3. 按提示打开辅助功能；不需要给屏幕录制。
4. 没有 Dock 图标，入口在菜单栏 ••• 和收纳条右侧齿轮。

## 已知限制

- 私有 `MenuBarClientCore` 接口，macOS 更新可能失效；不能上 App Store
- 多显示器未验证
- 没有自动更新
- ad-hoc/自签名构建可能在更新后要求重新授权
- 角色素材非官方授权；权利方请联系 `wuyiyang.studio@gmail.com`

# YoungBar 0.1.1

## 新功能

- **键盘优先**：⌃⌥B 打开收纳条并选中第一项；直接输入名称筛选（英文名、bundle id 也能匹配），← → 选择，回车打开，Esc 先清空再关闭，⌘, 打开设置。
- **自定义快捷键**：「通用 → 快捷键」点一下再按新组合；Esc 取消，⌫ 清除；被其他应用占用时保留原来的。
- **放不下的图标进收纳条**：菜单栏满时 macOS 27 会把放不下的图标收进刘海旁的 «，它们现在也出现在收纳条里，有空间时自动回到菜单栏。可在「通用」里关闭。
- **配置导入导出**：每个图标的状态、顺序和所有选项存成一个 JSON。
- **首次启动引导**：授权和基本用法；「通用 → 使用引导」可再次打开。
- **检查更新…**：••• 菜单里打开 GitHub Releases（app 本身不联网）。

## 改进与修复

- 空闲 CPU 从约 1.7% 降到约 0.3%：不再每秒完整扫描一次菜单栏，改为按需刷新。
- 菜单栏拥挤时 ••• 不再跑到刘海下面看不见。
- 用最新命令行工具（Swift 6.4）从源码构建失败的问题已修复，仍然不需要 Xcode。
- 正式版不再包含真机自检代码，也不再链接 ScreenCaptureKit。
- 关于窗口的版本号改为读取 app 自身版本。
- 安装脚本总是安装最新版，升级前先正常退出正在运行的 YoungBar。

## 要求

- macOS 27
- 辅助功能权限（设备控制与数据访问）；不需要屏幕录制

## 安装 / 升级

```sh
curl -fsSL https://raw.githubusercontent.com/51younglowkey/youngbar/main/Scripts/install.sh | sh
```

或下载 `YoungBar-0.1.1.zip`，解压后拖进 `/Applications`，第一次右键 → 打开。

## 已知限制

- 多显示器没有验证
- 私有 `MenuBarClientCore` 接口，macOS 更新可能失效；不能上 App Store
- 角色素材非官方授权；权利方请联系 `wuyiyang.studio@gmail.com`

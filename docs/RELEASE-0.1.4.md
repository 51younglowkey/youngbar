# YoungBar 0.1.4 更新日志

## 新增

- **自动检查更新**：每天向 GitHub 查一次新版本。有新版本时 ••• 右上角出现一个小圆点，右键菜单第一行「有新版本，点此更新…」，点一下即可下载安装。不会弹窗打扰，也不会自己安装。
- **数字键直接打开**：用快捷键打开收纳条时，前 9 个图标下方标出 1–9，按数字直接打开对应图标。
- **收纳条里拖动排序**：在收纳条里按住图标左右拖，就能换位置。菜单栏不会闪动。
- **新图标自动收纳**（默认关闭）：打开后，新装应用第一次出现在菜单栏的图标会直接放进收纳条，不再挤占菜单栏。系统图标不受影响。在「通用 → 收纳条」里打开。

## 调整

- **默认快捷键**：⌃⌥B → **连按两下 ⌘**。单手就能按，也避开了 Claude（连按两下 ⌥）和 ChatGPT（⌥ 空格）的默认快捷键。⌘C、⌘V 这类组合键不会误触发。
  - 自己改过快捷键的用户保持不变。
  - 设置里录快捷键时，除了组合键，也可以连按两下 ⌘ / ⌥ / ⌃。

## 移除

- **收纳条打字搜索**：收纳条里一般只有几个图标，看一眼就能找到，搜索反而多一步。现在用数字键代替，打开收纳条后按 Esc 直接关闭。

## 修复

- **菜单栏多出一个 •••，和图标叠在一起**（0.1.3 已先修复）
  - 现象：一部分用户的 ••• 旁边多出一组点，看起来像两个隐藏按钮重叠。
  - 原因：••• 是浮在菜单栏上的小窗口，下面垫着 YoungBar 自己的一个菜单栏项占位，那个项的标题也是「•••」。有图标需要隐藏时，macOS 不画这个占位项；**没有任何图标需要隐藏时**（刚装好还没隐藏东西，或者隐藏的应用都没打开），macOS 就把它画了出来，于是出现两个 •••。
  - 处理：占位项改成空白，只负责占位置，图标只由上面那个小窗口画。现在不管有没有隐藏图标，都只会看到一个 •••。

## 说明

- 应用内更新会自动检查，这次之后升级只要点圆点菜单里的那一行。
- 0.1.2 / 0.1.3 用户：这次还需要手动点一次 ••• 菜单里的「检查更新…」，升级到 0.1.4 之后就会自动提醒了。


# YoungBar 0.1.4 更新日志

## 新增

- 连按两下 ⌘ 打开收纳条
- 按 1–9 直接打开图标
- 收纳条里拖动排序
- 右键图标改显示方式
- 新图标自动收纳（可选）
- 有新版本时 ••• 出现圆点
- 更新后显示更新内容
- 菜单里复制诊断信息

## 优化

- 设置项精简，分类更清楚
- 点击 ••• 只打开收纳条

## 移除

- 收纳条打字搜索
- 「在菜单栏中展开」（会重影）

## 修复

- 多出一个 •••（占位项被系统画出，已改为空白）

## 说明

- 默认快捷键从 ⌃⌥B 改为连按两下 ⌘；自己改过快捷键的保持不变。
- 0.1.2 / 0.1.3 用户：这次需要在 ••• 菜单里点一次「检查更新…」，之后有新版本会自动提醒。
- 0.1.1 及更早版本：

```sh
curl -fsSL https://raw.githubusercontent.com/51younglowkey/youngbar/main/Scripts/install.sh | sh
```

## 校验

```sh
shasum -a 256 -c YoungBar-0.1.4.zip.sha256
```

对应源码：本 tag（`v0.1.4`）的源码归档。

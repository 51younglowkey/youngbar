# YoungBar 0.1.6 更新日志

## 修复

- ••• 跟随当前桌面的菜单栏颜色

## 要求

- macOS 27 或更新，Apple 芯片的 Mac；更早的系统（macOS 26 及以前）打不开
- 设备控制与数据访问（辅助功能）权限；不需要屏幕录制

## 说明

- 各个桌面的壁纸明暗不同时，切桌面后 ••• 约 1 秒内变成和其他图标一样的颜色，不用再重启 YoungBar

# English

## Fixed

- ••• follows the menu bar on every desktop

## Requirements

- macOS 27 or later on an Apple silicon Mac; it won't open on earlier versions (macOS 26 and before)
- Device Control and Data Access (Accessibility) permission; no Screen Recording

## Notes

- With light and dark wallpapers on different desktops, the ••• takes the same colour as the other icons within about a second of switching; no restart needed
